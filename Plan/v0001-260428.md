## 작업 사항
- `Plan` 폴더를 추가하여 사용자 수정 요청 및 업데이트 지시 사항을 md 파일로 기록할 수 있도록 구성했다.
- 업데이트 로그 파일명은 `vNNNN-YYMMDD.md` 형식을 사용한다.
- 버전 번호는 `0001`부터 `9999`까지 순차 증가하며, 날짜 식별자는 사용자 지정 날짜의 `YYMMDD` 값을 사용한다.
- 각 로그에는 코드 수정 기록 전반, 관련 이전 버전, 전체 작업 사항을 기록한다.
- `Plan` 폴더는 저장소 변경 사항과 함께 Git 커밋 대상에 포함한다.
